# NEXT ZODI — Premium Men's Fashion

NEXT ZODI is a modern men's fashion e-commerce website featuring premium outfits, stylish collections, elegant product cards, and a seamless shopping experience. Designed with a luxurious black-and-gold theme, it delivers a sophisticated and responsive shopping interface.

## ✨ Features
- Premium men's fashion collections
- Modern black-and-gold UI
- Stylish product cards and product ratings
- Wishlist and shopping cart UI
- Responsive website design
- Elegant animations and interactions

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started
1. Clone or download this repository.
2. Open the project folder.
3. Run `index.html` in your browser.
